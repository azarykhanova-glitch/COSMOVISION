# COSMOVISION
 это инновационный стартап-приложение, посвящённое мониторингу космического пространства и анализу орбитальной обстановки вокруг Земли. Особое внимание уделено проблеме космического мусора, ориентировано на повышение осведомлённости о состоянии околоземного пространстваи обеспечение безопасности спутниковых систем.
